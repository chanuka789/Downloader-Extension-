## Detailed description
MediaHarbor finds every image and video on the page and saves it in the best quality the website offers.

★ Best quality, automatically
• Picks the largest version of every image (srcset, lazy-loaded and linked originals)
• Turns thumbnails into full-size originals on many popular sites
• Quality badges: 4K, Full HD, 1080p, 720p

★ Download buttons on Instagram
• A Download button on every post, reel and story
• Carousels: save the slide you see, or all slides
• Round buttons on Explore, search, hashtag and profile grids
• Bulk mode: select many posts and download them at once
• Files named by user and post, saved in full quality

★ HD videos and streams
• Saves HLS and DASH streams in the highest quality
• Joins video + audio into one MP4 without losing quality
• Shows progress while videos are prepared

★ Easy to use
• Toolbar popup and a full-page view
• Search, filters, preview, keyboard shortcuts
• Light and dark theme; works on desktop, tablet and phone-sized windows
• Files are organised in Downloads/MediaHarbor/<website>

★ Private
No account, no servers, no tracking. Everything runs in your browser.

Please respect copyright: only download content you own or have permission to use. DRM-protected videos, live streams and YouTube videos are not supported.

## Single purpose (for the review form)
Find images and videos on the current web page and download them in the best available quality.

## Permission reasons (for the review form)
- downloads: save the files the user chooses
- tabs / host permissions (<all_urls>): find media on the page the user is viewing
- scripting: add the media finder to pages that were open before installation
- webRequest: detect video streams (HLS/DASH) that the page loads
- declarativeNetRequestWithHostAccess: send the page's referrer when downloading files that need it
- offscreen: join video and audio into one MP4 file
- storage / unlimitedStorage: keep settings and the list of found media
- contextMenus: "Save in best quality" right-click option
